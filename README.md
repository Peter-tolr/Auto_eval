# 黑龙江大学 学生评教 自动填写脚本

自动完成本学期「学习体验调查」和「学生评教」两份问卷：登录统一身份认证 → 打开教学评价系统 → 逐份填写并提交。

## 环境要求

- Windows + Microsoft Edge（脚本会直接调用已安装的 Edge）
- Python 3.9+，安装依赖：

```powershell
python -m pip install selenium
```

## 快速开始

1. 打开 `accounts.json`，填入学号和密码（可放多个账号）：

```json
{
  "20770888": {"password": "你自己的的密码", "name": "张某三"},
  "20880001": {"password": "另一个密码", "name": "李某四"}
}
```

2. 运行：

```powershell
python pj.py                 # 有多个账号时会出现编号菜单，可手动切换
python pj.py -a 20240888     # 直接指定账号
python pj.py -a 20240678 --dry-run    # 只填写、不提交（先看效果）
python pj.py -a 20240678 --limit 1    # 只做 1 份
python pj.py --list          # 列出已配置的账号
```

3. 浏览器会自动弹出并自行操作，**不要手动关窗口**。结束后窗口自动关闭。

## 常用参数

| 参数 | 说明 |
| --- | --- |
| `-a, --account` | 学号；不填则弹出菜单选择 |
| `-p, --password` | 临时指定密码（不写入文件） |
| `--limit N` | 最多提交 N 份问卷 |
| `--dry-run` | 只填写不提交，用于检查效果 |
| `--headless` | 无头模式，不显示浏览器窗口 |
| `--yes` | 跳过开跑前的确认提示 |
| `--fresh` | 用全新的配置目录启动（相当于换一台干净电脑，需要重新登录） |

## 工作原理

1. 用持久化浏览器配置目录 `.profiles/<学号>` 启动 Edge，直接打开教学评价系统
   `https://zlpj.hlju.edu.cn/static/vue/vue/`。
2. 如果系统把浏览器弹到统一身份认证页，就在那一页用账号密码登录；CAS 带着 ticket 跳回评价系统，
   SPA 自动换取登录态并进入首页（窗口不会先跳到信息门户）。
   首次运行（配置目录里还没有 cookie）约需 1~2 分钟，之后 10 秒左右即可进入。
3. 点「去完成」进入问卷列表，循环点击「去填写」→ 填写 → 提交，直到「已评问卷数 = 本学期应评」。
4. 每份问卷的答案由打分策略生成：
   - 绝大多数题目选最高档「完全符合」；
   - 随机 1~2 题降一档为「符合」（偶尔一题降到「基本符合」）；
   - 保证：不会全部满分、不会全部雷同、平均分 ≥ 0.9；
   - 主观题从 `comments.json` 的正面评价/改进建议里随机抽取。
5. 每份问卷的随机种子、选项分布、提交结果都写入 `logs/<学号>_<时间>.jsonl`。

## 目录说明

```
pj.py                 入口脚本
accounts.json         账号密码（请勿外传）
settings.json         配置（配置目录、间隔等）
comments.json         主观题文案库，可自行增删
hlju/
  browser.py          启动 Edge、等待/点击/截图等工具
  login.py            打开评价系统 + 就地完成统一身份认证登录
  forms.py            问卷解析、填写、提交
  scoring.py          打分策略
  runner.py           整体流程与日志
tests/test_scoring.py 打分策略单元测试
logs/                 运行日志（jsonl）
screenshots/          失败时自动截图、每份问卷填写后截图
```

跑测试：

```powershell
python -m unittest discover -s tests -v
```

## 注意事项

- **二次验证**：校外网络登录统一身份认证可能触发短信/微信/邮箱二次认证，脚本会停下并截图（`screenshots/err_sso.png`），此时请手动在弹出的浏览器里完成验证，或改用校园网/VPN。
- **重复运行是安全的**：已完成的问卷不会重复提交，脚本会自动跳过。
- **登录慢是正常的**：统一身份认证首页约需 20~30 秒渲染，脚本已按此设置等待时间。
- 密码以明文保存在 `accounts.json`，请勿把该文件发给他人；也可以不写密码，运行时用 `-p` 临时输入。
